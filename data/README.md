# Data

이 폴더에는 Tableau 분석에 사용한 공개 데이터 기반 통합 Mart를 포함합니다.

## Included

- `Hana_Decision_Intelligence_Tableau_Mart_v3_KR.xlsx`

이 파일은 시장·정책·결제 레일·은행 비교·하나은행 FX/GLN/GIWA 관련 공개 근거를 Tableau에서 사용할 수 있도록 구조화한 분석용 Mart입니다.

주요 Tableau 관련 시트에는 다음 범주의 데이터가 포함됩니다.

- Payment rail benchmark
- Cross-border friction taxonomy
- Global infrastructure projects
- Hana FX execution evidence
- GLN network / usage evidence
- Digital rail roadmap
- Cross-border target KPI
- Decision matrix
- Tableau claim registry
- Executive summary
- Dashboard plan
- Calculated fields
- Build checklist

## Data Policy

- 회사 내부 데이터는 포함하지 않습니다.
- 공개 출처를 기반으로 구성한 분석 데이터입니다.
- 원 출처의 라이선스 및 이용조건은 각 기관의 정책을 따릅니다.
- GitHub 재배포 시 원문 자료 전체를 복제하기보다 출처 링크와 분석 Mart를 중심으로 유지하는 것을 권장합니다.
