# Hana analysis changes

Read `docs/methodology.md`, `docs/data_sources.md`, `PACKAGE_MANIFEST.md`, and `docs/publish_checklist.md` before changing an analytical claim or artifact. For substantive work, record the analysis question, evidence, plan, and tasks in `docs/changes/<id>/`.

Trace each material claim to a public source and date. Keep PoC, production integration, live commercialization, and commercial economics distinct. Check that Excel, Tableau workbook/package, screenshots, and presentation tell the same story. Review public metadata before publication.

Inspect any external tool, skill, or script before running it. Do not introduce dependencies merely to validate artifacts. Report changed claims, source evidence, artifact checks, and any unverified statements.
